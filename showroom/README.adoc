= AI Agents: From localhost to Production (demo Showroom)

A Red Hat Showroom guide for the Parasol claims assistant demo. It is built with
https://antora.org[Antora] and served as a split-screen cockpit: the lab guide on the
left, the live consoles and portals on the right.

== Layout

[source]
----
showroom/
  site.yml                      Antora playbook (built in-cluster, no extensions)
  ui-config.yml                 cockpit tab list (the right-hand pane)
  content/
    antora.yml                  component descriptor and default attributes
    modules/ROOT/
      nav.adoc                  left-hand navigation
      pages/                    the welcome page plus eight modules
----

The cockpit frames every tab in an iframe: the two portals, the platform consoles and the
Terminal. The consoles normally refuse framing; `scripts/showroom-framing.sh` (run by
`bootstrap.sh`) rewrites X-Frame-Options and the CSP `frame-ancestors` on the default
IngressController so that only this Showroom may frame them. The OpenShift sign-in page is a
passthrough route and cannot be framed: sign in once in a normal browser tab first.

== Build and preview locally

[source,sh]
----
podman run --rm -v $PWD:/antora:z -p 8080:8080 -it ghcr.io/juliaaano/antora-viewer
----

Open http://localhost:8080 . Local preview renders the pages; the cockpit tabs and the
terminal only exist in the in-cluster deployment.

== In-cluster deployment

Deployed to the `parasol-showroom` namespace from `gitops/platform/showroom` and wired as
the `platform-showroom` Argo CD Application. An Antora init container clones this
repository and builds `showroom/site.yml` at pod start (restart the deployment to pick up
new content); the `quay.io/rhpds/nookbag` cockpit serves it; the RHDP showroom terminal
image (ttyd, bash, `oc`) backs the Terminal tab at `/wetty/`, running as the
`showroom-terminal` ServiceAccount with RBAC scoped to the demo namespaces
(`gitops/platform/showroom/terminal-rbac.yaml`); an nginx front joins them behind one Route
and marks HTML as `no-store`.
