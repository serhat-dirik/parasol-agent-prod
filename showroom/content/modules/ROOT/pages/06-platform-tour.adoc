A thirty-second stop at each console behind the secured agent. This is the map of where every control lives.

[NOTE]
.Know: why the tour matters
====
The value to land is that none of this is bespoke. Every control is a product console an operator already knows: identity in Keycloak, model access and guardrails in OpenShift AI, traffic and budgets in the gateway and the dashboard, delivery in Argo CD, runtime security in Advanced Cluster Security. The agent did not need a new platform. It needed the platform the customer already runs. Keep each stop to thirty seconds and name the one thing it controls.
====

[NOTE]
.Screens for this module
====
These consoles are auth-walled, so they are captured in the logged-in operator browser at record time. Each step names the exact object or URL to open.
====
